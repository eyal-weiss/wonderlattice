# Provenance

Wonderlattice v0.2.0 was first written with ChatGPT agents and exported on 2026-09-23 (UTC) from original source commit
`79d85f89e579e30a8cd6e2a68028f5f6743e7c0c`. The export's `index.html` had SHA-256
`0fa0cd5625f001abcabeba818c3275aacc6299e2091c7012dd3818ab2942517b`. It excluded hosting configuration, credentials,
earlier git history, downloaded dependencies, and build output.

Since then, this repository's git history is the record. Pull requests #1, #2, and #4 added the traffic room,
mathematician visitors, and My trail. The v0.3.0 maintainability refactor split the app into readable files without
changing visitor behaviour (see docs/STATUS.md for how that was verified).

The portraits come from Wikimedia Commons under the terms listed in docs/PORTRAITS.md.
